FileShare iPhone 支持

输入公开 GitHub 仓库地址，浏览默认分支，预览文件，再通过 iOS 文件选择器把副本保存到本地或你选择的云盘。

1 · 打开仓库

粘贴 `https://github.com/所有者/仓库` 地址。当前版本仅支持无需登录即可访问的公开仓库。

2 · 浏览文件

文件夹优先显示。下拉列表可重新载入当前目录，右上角菜单可以回到 GitHub 网页。

3 · 预览

点按文件后，App 会下载只读副本并交给 iOS Quick Look。实际格式支持由当前 iOS 版本决定。

4 · 另存副本

点按下载图标，在系统文件选择器中选择“我的 iPhone”、iCloud Drive 或其他已启用的位置。

系统要求

iPhone，iOS 17 或更高版本。App 不与 Mac 版同步，不需要 FileShare 或 GitHub 登录，不会修改仓库内容。

常见问题

为什么提示找不到仓库？

请确认地址来自 `github.com`、包含所有者与仓库名，并且仓库是公开的。私有仓库在 GitHub 未登录状态下也会表现为找不到。

为什么提示达到请求限额？

GitHub 对同一 IP 的未登录公开 API 请求设有限额。App 会显示可用的重置时间；等待后重试即可。

为什么某个文件无法预览？

文件可能没有直接下载地址、超过 GitHub Contents API 的支持范围，或格式不受当前 iOS Quick Look 支持。你仍可在仓库菜单中前往 GitHub 查看。

下载的文件在哪里？

预览副本保存在 App 的可清理缓存。只有点按“存储到文件”并完成系统选择器后，才会在你选择的位置生成长期副本。

内容与滥用举报

FileShare 不托管仓库内容。若公开仓库包含侵权、违法或滥用内容，请使用 GitHub 举报入口；也可以把仓库地址和问题说明发送至 github@clawsphere.cn，我们会评估是否需要在 App 侧采取措施。

联系技术支持

发送邮件至 github@clawsphere.cn。请附上 iOS 版本、仓库地址、操作步骤和错误提示；请勿发送私钥、Token、密码或非公开文件。

隐私说明见 FileShare 隐私政策。

English support

FileShare requires iOS 17 or later and supports public GitHub repositories only. Paste a repository URL, browse the default branch, tap a file to preview it, and use Save to Files to export a copy. For help, email github@clawsphere.cn. Do not send passwords, tokens, private keys, or private files.
