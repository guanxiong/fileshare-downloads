Privacy · 隐私

隐私政策

FileShare iPhone App 是公开 GitHub 仓库的只读浏览器。它无需账号，不含广告、分析或追踪，也不会把仓库地址和文件内容发送给 FileShare 开发者。

生效日期：2026 年 8 月 27 日 · 适用于 FileShare iPhone App 1.0 及以上版本

我们不收集的数据

FileShare 开发者不收集、存储或出售个人信息、设备标识符、精确位置、联系人、使用分析、崩溃遥测、用户输入的 GitHub 地址或用户预览的文件内容。App 不创建 FileShare 账号，也不集成第三方广告或分析 SDK。

GitHub 请求

当你输入公开仓库地址时，App 会从你的设备直接连接 GitHub 的 API 与内容域名，以读取仓库元数据、目录和你选择预览或下载的文件。FileShare 不代理这些请求。

GitHub 可能按照其自身政策处理网络请求信息，例如 IP 地址、请求时间和所访问的公开资源。请参阅 GitHub 隐私声明。FileShare 与 GitHub, Inc. 没有隶属或背书关系。

设备上的文件

为了提供预览，App 会把所选文件临时下载到 iOS 可清理的 App 缓存中。缓存位于 App 沙盒，不会同步到 FileShare 服务。iOS 可以自动清理缓存；卸载 App 会移除其沙盒数据。

当你选择“存储到文件”时，系统文件选择器会把副本保存到你指定的位置。该副本由你和所选存储提供商管理。

安全与儿童隐私

所有远程请求使用 HTTPS，App 只接受 `github.com` 仓库地址和 GitHub 内容下载域名。FileShare 不面向儿童收集信息，也不会明知收集儿童个人数据。

政策更新与联系

如果 App 的数据实践发生实质变化，我们会在此页面更新政策并修改生效日期。关于隐私的疑问可发送邮件至 github@clawsphere.cn。

English summary

FileShare for iPhone is a read-only browser for public GitHub repositories. The developer does not collect personal data, repository URLs, file contents, analytics, identifiers, or telemetry. Requests go directly from your device to GitHub over HTTPS and are subject to GitHub's privacy statement. Selected files are held in the app's purgeable cache; copies exported through the system Files picker are controlled by you. Privacy questions: github@clawsphere.cn.
